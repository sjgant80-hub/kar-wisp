wisp

by Kar · kernel-backed · deterministic · no LLM judge

Checks a claim about a public GitHub repo — a source file, a gate/test companion, a cross-referenced phrase — against GitHub's own real, public API. Not a judge. A receipt.

What this actually checks

Three specific, named things — nothing broader claimed: does the claimed source file exist in the repo; does a claimed gate/test companion file exist; does a claimed cross-reference file genuinely contain the claimed phrase. Every check is a live call to api.github.com, GitHub's own public REST API — re-runnable by anyone, not just trusted. It does not judge whether code is correct or a claim's substance is true — only whether these three checkable facts are real.
